# GitHub replacement instructions

This archive is prepared to replace the published static website files in the repository root.

1. Open the repository folder cloned by GitHub Desktop.
2. Extract this archive directly into that folder and allow files to be replaced.
3. Review the changed files in GitHub Desktop.
4. Commit with `perf: optimize portfolio interaction and loading` and push to GitHub.

The archive intentionally does not include the repository's `.git` folder. Keep the existing Git history and remote configuration.

The old PNG page exports are no longer referenced because they were replaced by JPEGs. Leaving those old files in the repository will not break the website, but deleting them in GitHub Desktop will keep the repository smaller.
